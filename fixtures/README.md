# Parity fixtures

Ground truth generated by running the **Python** implementation in
`ap_sw_github_work_report_generator` over these inputs. The TypeScript port is
checked against them in CI.

- `python-categories.json` - `[{ m: message, c: category }]` from
  `categorize_commit`.
- `python-ignore-paths.json` - `{ path: boolean }` from `_path_is_ignored`.

## Why the messages are synthetic

An earlier version of this fixture used 4,936 real commit messages from a
private organization, which agreed exactly. It was replaced because commit
messages are the employer's content and this repository may be opened up.

The synthetic set is also the better test. It walks **every keyword in the
category table**, most of which never occur in any one organization's history,
plus the cases that only exist to be handled: two-category messages that must
resolve by first word and then by table order, version and ticket prefixes the
punctuation trim exists for, merge short-circuiting, keyword-free domain nouns
that must reach Improvements rather than Other changes, and degenerate input.

## Regenerating

Run `categorize_commit` and `_path_is_ignored` from `github_work_report.py` over
the same inputs and write the results in the shapes above. If the Python
implementation is no longer available, these files become the specification: the
behaviour they describe is what shipped and was verified.
